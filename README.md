### GENII
GENII is a documented set of programs for calculating radiation dose and risk from radionuclides released to the environment. It estimates radionuclide concentrations in the environment and dose to humans from acute or chronic exposures resulting from radiological releases or initial contamination conditions. Although the code was initially developed for the U.S. Environmental Protection Agency (EPA), regulators and decision makers in other federal agencies, including several outside the U.S., employ this state-of-the-art, technically peer reviewed system to analyze hazards and design controls to prevent or mitigate potential accidents. The GENII code is developed by Pacific Northwest National Laboratory for the Department of Energy.

The current version is 2.10.
